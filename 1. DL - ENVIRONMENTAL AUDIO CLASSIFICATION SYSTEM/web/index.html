01 / THE CONCEPT

BEYOND WHAT WE HEAR

Making sense of
the soundscape.

Environmental audio carries information about the world around us. This project explores how machine learning can learn sound patterns and assign an audio recording to a predicted category.

Upload a supported recording to test the trained model. The application processes the audio, extracts features, and returns its predicted class.
